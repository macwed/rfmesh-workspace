# Archive

Files in this directory are **historical / superseded** but kept for project archaeology. They are not load-bearing for current development.

## Contents

- `WS-A-to-Lead.md` / `WS-B-to-Lead.md` / `WS-CD-to-Lead.md` — handoff notes from the three mid-level Opus workstream agents (pre-2026-05-17) to the lead. The mid-level-Opus model was retired per `HANDOFF_TO_CLAUDE_CODE_LEAD.md` §2; current ownership is lead-Opus + council subagents + collaborators per `docs/WORK-SPLIT.md`. Contents preserved here as historical record of design intent that shaped the early architecture.

## Promotion rules

A file in this directory **is not consulted for current decisions**. If you find yourself wanting to act on something here, escalate to the lead first — the operative version of that decision lives in a current binding doc (`ARCHITECTURE.md`, `AGENTS.md`, `INTERFACES.md`, `WORKSTREAMS.md`, `INHERITED_CONTEXT.md`) or an ADR.

If you find a current binding doc *contradicting* an archive file, the binding doc wins. File a SCRATCHPAD note pointing out the discrepancy so the lead can either correct the binding doc or annotate the archive file with a "superseded by" line.
