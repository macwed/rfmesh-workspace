# TICKET WS-A-001: Scaffold rfmesh-sdr package and implement single-channel SyntheticReceiver against the Receiver Protocol

## Goal (one sentence)
Stand up the `packages/rfmesh-sdr/` package as a uv-workspace member and
land a deterministic, resamplable, single-channel `SyntheticReceiver` that
structurally satisfies `rfmesh_contracts.protocols.Receiver`, generating
baseband IQ from a configurable emitter + antenna + noise scenario so
Workstream B can begin building the L1 `BearingEstimator` against it.

## Acceptance criteria

1. `uv run pytest packages/rfmesh-sdr -v` passes. The following tests are
   added and pass:

   a. `tests/test_protocol_conformance.py::test_synthetic_receiver_is_receiver`
      — `isinstance(SyntheticReceiver(scenario), Receiver)` is True
      (Protocol is `@runtime_checkable`).

   b. `tests/test_protocol_conformance.py::test_capabilities_shape`
      — `receiver.capabilities()` returns an object where
      `is_power_calibrated is False`, `n_coherent_channels == 1`,
      `driver == "sim"`, and `actual_sample_rate_hz` equals the configured
      rate.

   c. `tests/test_read_exact.py::test_read_returns_exact_n_samples`
      — `read(n)` returns a 1-D `numpy.ndarray` of dtype `complex64` and
      shape `(n,)` for several n in {1, 1024, 65536}.

   d. `tests/test_read_exact.py::test_read_zero_raises`
      — `read(0)` raises (programming error: caller asks for nothing).

   e. `tests/test_determinism.py::test_same_seed_same_iq`
      — Two `SyntheticReceiver(scenario, seed=42)` instances produce
      byte-identical IQ for matched `read(n)` call sequences.

   f. `tests/test_determinism.py::test_reseed_changes_noise_keeps_signal`
      — One receiver, called `reseed(s)` with two different `s`, produces
      different IQ blocks for the same `read(n)` call, but the mean
      complex amplitude of the deterministic emitter component (computed
      against the known ground-truth steering) agrees within a small
      tolerance — i.e. signal is preserved, only noise realization changes.

   g. `tests/test_lifecycle.py::test_open_configure_read_close`
      — Full lifecycle: `open()`, `configure(node_config)`, several
      `read(n)`, `close()`. `close()` is idempotent (callable twice
      without raising).

   h. `tests/test_peakfind.py::test_yagi_sweep_peak_locates_emitter`
      — A CW emitter at azimuth θ = 137°, range 1500 m, frequency
      915 MHz, plus a parametric Yagi antenna pattern with HPBW = 50°
      (the ATK-10 nominal). Sweep heading from 0° to 359° in 1° steps,
      compute relative RSSI per heading from `read(8192)` as
      `10*log10(mean(|iq|**2))`, find argmax. Recovered peak is within
      ±5° of true azimuth at SNR = 20 dB. The RSSI computation is an
      inline test helper, **not** an import from `rfmesh_dsp`.

## Design hints (non-binding, but read these before designing the API)

The simulator is a first-class component, not a mock. The architecture
expects this to be expanded to multipath, two-ray-ground, log-normal
shadowing, IQ imbalance, ADC quantization, and per-channel phase/gain
offsets in subsequent tickets, and **possibly updated based on the Phase
C smoke test outcome** (see INHERITED_CONTEXT.md §3.1). Design with
that growth in mind:

- `SimulationScenario` is an immutable frozen dataclass holding:
  emitters tuple, antenna pattern, channel model (Protocol), noise
  floor in dBFS, sample rate in Hz, optional array spec (None for L1).
  Validation: at least one emitter, sample rate > 0, noise floor
  finite.

- `SyntheticReceiver` holds: scenario (immutable), RNG manager (state),
  current antenna heading (float, mutable via
  `set_antenna_heading(deg)`; defaults to 0.0), retuned config
  (set on `configure()`), and an opened/closed flag.

- The RNG manager wraps `numpy.random.SeedSequence` and exposes
  dedicated `Generator`s per noise stream (per-channel, per-emitter
  jitter, per-phase-error), spawned from one root seed. `reseed(s)`
  resets all of these to a new root, so a new call sequence gives a
  fresh noise realization without touching the deterministic emitter /
  antenna geometry.

- The `Receiver.read(n)` semantics: given current heading H,
  scenario S, and the RNG state, return n complex64 samples representing
  the superposition of (free-space-attenuated emitter signal weighted
  by the antenna pattern at angle (θ_emitter − H)) for every emitter,
  plus AWGN at the noise floor. CW emitter → constant complex tone at
  baseband (e.g. zero IF) with amplitude derived from free-space PL +
  antenna gain; the absolute scale is arbitrary because SDRs are not
  power-calibrated (INHERITED_CONTEXT.md §1.3) — only RELATIVE RSSI
  must be physically correct.

- The "antenna pattern" for the parametric Yagi: a smooth cosine-taper
  approximation with main lobe HPBW and a front-to-back ratio, e.g.
  G(Δθ) = max(cos²(π · Δθ / (2 · HPBW)), back_lobe_floor) with Δθ
  normalised to [-180°, +180°]. Document the formula in a docstring;
  the test in (1h) only checks peak location, not pattern fidelity.

- `read(n)` raises `ReceiverNotOpenError` (define in `exceptions.py`)
  if `open()` has not been called or `close()` has. This is the
  Inv. 4 surface that the L1 estimator and node runtime depend on.

- The `ChannelModel` Protocol surface (minimal in this ticket): one
  method `apply(samples: np.ndarray, distance_m: float,
  frequency_hz: float, rng: np.random.Generator) -> np.ndarray`.
  `FreeSpaceChannel.apply` multiplies by the Friis-derived complex
  attenuation; no delay, no taps. Defining the Protocol now (even
  with one implementation) is what lets WS-A-003 add
  `MultipathFIRChannel` etc. without touching `SyntheticReceiver`.

- The cosmetic helpers `EmitterSpec`, `AntennaPattern`,
  `SimulationScenario`, `ReceiverImpairments` should be `pydantic`
  models with `ConfigDict(frozen=True, extra="forbid")` — same
  discipline the contracts use, applied to internal data. This is
  not a contract change; it is internal hygiene.
